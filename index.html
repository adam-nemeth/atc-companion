Configuration

“Write config” keeps each sensor's own hardware‑specific bits and calibration offsets. Files whose name contains a sensor's ID (like Kitchen-ATC_xxxxxx-config.json) go to that sensor only; any other file is used for all ticked sensors without their own file.

History download

These options also apply to “Download all”.

Clock drift: a sensor's clock can run fast or slow. The clock is read before downloading and, if it's off, the readings since the last clock set are shifted to the right time; the sensor's own times stay in the sensor_timestamp column.

Sensor configuration

Bluetooth name (shown in the Bluetooth picker)

Connect to a sensor to see its Bluetooth name.

Must start with ATC_ (so the Connect picker still lists it), up to 20 letters, digits, _ or -. The sensor applies the new name after you disconnect; the iPhone may keep showing the old name until Bluetooth is turned off and on.

Settings

Read from the sensor when you connect. Change values, then tap “Write config” - nothing is sent before that. Settings that say “leave as it is” mean different things on different models or firmware versions.

Sensor list

Your sensors and their descriptions are saved only in this browser on this phone - not in the web page. Load them from a devices.json (name, description, address), or let them be added as you connect.
