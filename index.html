Device configuration

Read on connect. Change values, then “Write config”. Fields marked hardware‑specific mean different things per model; leave them unless you know.

Bluetooth name (shown in the device picker)

Connect to a sensor to see its Bluetooth name.

Must start with ATC_ (so the Connect picker still lists it), up to 20 letters, digits, _ or -. The sensor applies the new name after you disconnect; the iPhone may keep showing the old name until Bluetooth is turned off and on. Your Windows scripts are unaffected (they use the address).

Sensor list

Your sensors and room names are saved only in this browser on this phone - not in the web page. Load them from the devices.json your Windows scripts use (name, description = room, address), or let them be added as you connect.
